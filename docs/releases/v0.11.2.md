Foldlet 0.11.2 fixes the extra notification that appeared after opening the cover panel.

Android creates a system notification when Foldlet displays its overlay. It arrives after the panel opens and was being included in Foldlet’s list, making the number of cards increase by one. The previous group-summary fix did not exclude this separate system notice.

- Excludes Android’s overlay status notice for Foldlet itself from the cover list and drawer badge counts.
- Matches the exact Android package and Foldlet-specific tag or channel, keeping other apps’ overlay notices and other system notifications available.
- Keeps notification contents, ordering, and the existing duplicate-summary filtering unchanged.
- The Android status notice remains under Android’s control. Foldlet does not cancel or disable it in the system notification panel.

Verified on the Galaxy Z Flip3 (SM-F711B): three consecutive notification-panel opens retained exactly two real Routines cards while Android’s overlay notice was active. Release build and six focused notification policy checks passed.

Install **Foldlet-0.11.2.apk** over the existing version and open Foldlet once. **Foldlet Controls 1.1.0** is unchanged. Both APKs and SHA-256 files are attached.
