Foldlet 0.9.0 refreshes the cover-screen controls.

- Two rows expand to fill the cover display, removing the large empty area below the tiles. Swipe up from the bottom edge still closes the panel.
- Live state labels for Wi-Fi, Bluetooth, hotspot, mobile data, sound, airplane mode, and location. Sound also changes its icon between ringing, vibration, and mute.
- Network mode shows the configured preference when One UI exposes it; Display shows automatic/manual brightness. Unavailable state is shown explicitly, without pretending the control is off.
- Uses the Samsung icons already installed in System UI where available, with built-in vector fallbacks for other devices. Samsung icon files are not bundled in the APK.

Update **both** APKs: **Foldlet-0.9.0.apk** and **Foldlet-Controls-1.1.0.apk**, then open Foldlet once. Controls 1.1.0 adds hotspot and configured network-mode state reads. Wi-Fi/Bluetooth still toggle on tap; long-press opens settings. One UI still restricts direct toggles for the other radio controls.

Both APKs are signed, non-debuggable beta builds. SHA-256 files are attached. On devices that warn about the compatibility helper’s older Android target, installation may require the per-app confirmation in Android’s installer.
