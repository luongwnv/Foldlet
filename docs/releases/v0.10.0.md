Foldlet 0.10.0 adds Samsung routine controls for Mobile data and Hotspot.

- Tap **Add routine** in **Settings > Samsung controls** to open a ready-made On/Off preset directly in Samsung's confirmation screen. Requires Samsung Routines+ from Galaxy Store.
- Link the four saved routines through Android's widget permission and Samsung's routine picker. Once configured, Mobile data and Hotspot toggle from the cover panel without USB, root, or Shizuku.
- Keep reverse actions disabled in each routine so ending it does not undo the requested setting. Samsung's import format resets this option; change it once in the native editor before saving.
- Live state verification reports failed changes. Long-press still opens system settings. Wi-Fi/Bluetooth continue to use Foldlet Controls.

Update **Foldlet-0.10.0.apk** and open it once. **Foldlet Controls 1.1.0** is unchanged and is included for Wi-Fi/Bluetooth controls and hotspot state detection. Existing links are kept across updates.

Checked on a Galaxy Z Flip3 (SM-F711B, Android 14 / One UI 6.1.1): native preset import, four widget links, and both directions of Mobile data/Hotspot toggling while folded. The radio controls use Samsung's user-bound widgets, not ADB commands. Samsung APKs and proprietary icon assets are not bundled.
