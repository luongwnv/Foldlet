Foldlet brings an app drawer and navigation to the **Galaxy Z Flip3 cover screen**, alongside Samsung’s native clock and widgets.

### In this beta

- New Foldlet / Glance identity with blue and yellow adaptive icons.
- Large app icons, search, favorites, sorting, hidden apps, and a toolbar that hides when scrolling.
- Right-edge access from the Samsung clock, leaving widget pages to Samsung.
- Standalone Back, Samsung Home, and Recent apps; Close all clears recent-app cards.
- English and Vietnamese following the system language, with an actual app drawer preview in Settings.
- Optional portrait and landscape rotation through the ADB helper while connected by USB.

### Install

Download **Foldlet-0.5.6.apk** below, install it, and open Foldlet on the inner screen. Grant Display over other apps and Accessibility; grant Usage access for Recent apps. See the [user guide and actual screenshots](https://github.com/luongwnv/Foldlet#readme).

This beta has been tested on **SM-F711B, Android 14 / One UI 6.1.1**. Close all clears Foldlet’s list without force-stopping apps. Some apps have navigation limitations on the cover screen. Forced rotation requires a computer; core features do not need a persistent USB connection.

The APK is a release build (`debuggable=false`), signed with the existing local development certificate to support updates over the installed test build. The keystore is not distributed. A SHA-256 checksum is included for download verification.
