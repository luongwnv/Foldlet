Foldlet 0.6.0 adds toolbar controls and a keyboard for the Galaxy Z Flip3 cover screen.

### New

- Toolbar placement: top, left, right, or bottom; four sizes from 28 to 56 dp; hide/show option.
- Force cover keyboard for focused text fields in other apps on Android 13+. Enable it in Settings; existing Accessibility access is used.
- Shared search keyboard with symbols, capitals, accented-character choices, and held Backspace.
- Offline swipe typing (Beta) with a basic English/Vietnamese vocabulary and installed app names in drawer search. Suggestions let you correct recognized words; vocabulary coverage is limited.
- Shorter About text and `luongwnv - 0.6.0` credit.
- Updated user guide with actual Recent apps and keyboard captures; removed archived design and reference-analysis files from the current source tree.

### Install

Install **Foldlet-0.6.0.apk** over your existing compatible build, then open Foldlet once. In Settings, use **Toolbar** for placement/size and **Keyboard** to enable Force cover keyboard or Swipe typing.

Keyboard input stays on the device and is sent only to the focused cover-screen editor. Existing field contents are not read. Password fields disable swipe suggestions. Some custom editors do not provide a compatible input connection. Swipe recognition is experimental and does not use a full commercial keyboard language model.

This is a beta build signed with the existing local development certificate, with `debuggable=false`. The SHA-256 file is provided for download verification. See the [user guide](https://github.com/luongwnv/Foldlet#readme).
