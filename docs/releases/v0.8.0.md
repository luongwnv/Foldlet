Foldlet 0.8.0 adds one-tap Wi-Fi and Bluetooth with the optional Foldlet Controls helper.

- Tap Wi-Fi or Bluetooth to switch it. Tiles show their actual on/off or changing state. Install both APKs below to use this without a computer, root, or Shizuku.
- Touch and hold a tile to open its system settings. Sound switches between ringing and vibration. One UI still restricts direct mobile data, hotspot, network mode, airplane mode, and location switching; use their long-press settings.
- Removed the Shortcuts title and Back button. Swipe up from the bottom edge to close the panel and return to Samsung Home.
- Shortcut selection and drag-to-reorder remain in Settings.

Install **Foldlet-0.8.0.apk** over your compatible existing version, plus **Foldlet-Controls-1.0.0.apk**, then open Foldlet once. Controls has no separate launcher and only accepts calls from the matching Foldlet certificate. It uses legacy compatibility APIs for Wi-Fi/Bluetooth, without scanning networks/devices or accessing the internet.

Both APKs are signed, non-debuggable beta builds. SHA-256 files are attached.
