Foldlet 0.10.1 makes the Recent apps close controls operate on Samsung tasks.

- **×** uses the matching task card's native Close action in Samsung Recent. Foldlet removes its history card after Samsung accepts the action. Locked, ambiguous, or unavailable targets are not guessed.
- **Close all** delegates to Samsung Recent's native Close all button, following Samsung's task rules.
- **Hold ×** to remove only a Foldlet history card. Recently used apps can remain in history after their task has already closed.
- Samsung Recent appears briefly during the operation; Foldlet returns automatically. No USB, root, Shizuku, or per-app routine setup is required. This closes tasks, not Android's Force stop operation.

Verified on a Galaxy Z Flip3 (SM-F711B, Android 14 / One UI 6.1.1): tapping × in Foldlet removed a dedicated test application's task from Android's actual Recent tasks. The task probe used a separate app so existing user apps were not closed during verification. Close all is wired to Samsung's native control; it was not run against the user's open apps.

Update **Foldlet-0.10.1.apk** and open Foldlet once. **Foldlet Controls 1.1.0** is unchanged and remains included for radio controls. Both APKs are signed, non-debuggable beta builds, with SHA-256 files attached.
