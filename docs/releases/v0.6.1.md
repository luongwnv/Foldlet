Foldlet 0.6.1 adds a **× close button at the top-right of each Recent apps card**.

- Close one card without opening its app or clearing the other cards.
- Dismissed cards stay hidden when reopening Recent apps and return after the app is used again.
- Close all still clears the entire list.
- Updated English/Vietnamese labels and actual Recent apps screenshot in the user guide.

Install **Foldlet-0.6.1.apk** over the existing compatible build, then open Foldlet once. Closing a card dismisses it from Foldlet; it does not force-stop the app or remove Android system tasks.

This beta is a signed release build with `debuggable=false`. A SHA-256 checksum is included. See the [user guide](https://github.com/luongwnv/Foldlet#readme).
