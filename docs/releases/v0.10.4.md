Foldlet 0.10.4 makes the cover keyboard less intrusive.

- The keyboard auto-shows only for a visible, focused, editable text field.
- Number, phone, and date fields keep their app keypad. Recognized calculator apps also keep their own keypad, including Samsung Calculator, whose formula field reports itself as a text editor.
- Use the keyboard button in Foldlet navigation to open it manually for these fields or reopen a dismissed keyboard.
- Restarting the same editor no longer closes/reopens the keyboard or cancels your dismissal. Typing continues through the renewed input connection.
- Changing fields, finishing input, or changing editor type invalidates the previous input target. Word replacement suggestions are invalidated when the connection restarts, so they cannot replace stale text.
- Updated the keyboard setting description in English and Vietnamese. Drawer search and its keyboard remain available.

Verified on an SM-F711B: Samsung Calculator launch and a native digit tap kept Foldlet's keyboard hidden. Dialer launch kept it hidden. A dedicated test editor confirmed typing across repeated connection restarts, dismissal surviving a restart, and manual reopening for text, number, and phone fields. The release build, Android lint, and five focused input-policy/session checks passed.

Install **Foldlet-0.10.4.apk** over the existing version and open Foldlet once. **Foldlet Controls 1.1.0** is unchanged. Forced rotation still requires the USB helper. Both APKs and SHA-256 files are attached.
