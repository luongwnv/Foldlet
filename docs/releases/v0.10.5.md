Foldlet 0.10.5 adds loading feedback to **Close all** in Recent apps.

- Close all replaces its text with the same animated circular indicator used by the individual × button while Samsung closes tasks.
- The header keeps the button’s width and position while loading. The original label is hidden underneath the indicator.
- Repeated actions stay blocked during task closing. If the temporary Foldlet menu layer cannot be prepared, the label and button state are restored.
- The menu refreshes when closing finishes, using the existing Samsung Recent task-closing behavior.
- Adds English and Vietnamese accessibility descriptions for closing all apps.

Install **Foldlet-0.10.5.apk** over the existing version and open Foldlet once. **Foldlet Controls 1.1.0** is unchanged. Both APKs and SHA-256 files are attached.
