Foldlet 0.7.0 separates home taps, navigation gestures, and system shortcuts.

- Tap a configurable area of the Samsung clock to open the app drawer. Settings include width, height, horizontal/vertical placement, enable/disable, and an indicator toggle, with a preview.
- Swipe inward from the right edge to open navigation. Swiping no longer opens the drawer on home.
- Swipe down from the top edge for Shortcuts. Choose available One UI controls in Settings, then touch and hold to drag them into order: Wi-Fi, Bluetooth, mobile data, hotspot, 4G/5G, sound, display, and more.
- Samsung widget pages keep their own touch controls. All home gesture windows are removed when leaving the clock page.
- Centered README images/tables and updated gesture guide.

Shortcuts open the OS control panels. Android restricts direct radio toggles for regular apps; some One UI controls may need the inner screen. Foldlet offers Open on phone when a control cannot be launched on the cover display.

Install **Foldlet-0.7.0.apk** over the existing compatible build, open Foldlet once, then configure **Home touch area** and **Home shortcuts** in Settings. This beta is a signed release build (`debuggable=false`), with a SHA-256 checksum attached.
